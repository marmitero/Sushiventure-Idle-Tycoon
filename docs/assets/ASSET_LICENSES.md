## Obrigações respeitadas neste projeto

1. Originais preservados sem modificação em `Sprites/` (versionados).
2. Derivados de runtime gerados por script em `public/assets/` (gitignored),
   sem substituir ou renomear originais.
3. Créditos mantidos: esta documentação + seção de créditos no jogo (Fase 11)
   citarão "Assets: CraftPix — Free Sushi Restaurant Game Asset Kit".
4. Não redistribuir o pacote como produto independente; não remover créditos;
   não usar os recursos para treinar modelos de IA.
5. Fontes sugeridas (`Sprites/FontLink.txt`): Google Fonts (Bebas Neue, Passion
   One, Lilita One) — licença OFL; o jogo carrega **Lilita One** via CSS com
   fallback de sistema.
